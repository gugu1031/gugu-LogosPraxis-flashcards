# LogosPraxis v1.0.0

LogosPraxis 的首个公开版本，提供本地优先的闪卡复习、学术 PDF 阅读、全文检索和学习数据统计能力。

## 本版内容

- 基于 FSRS 的四档复习与长期排程
- 本地 PDF 导入、阅读、页码定位与闪卡关联
- 闪卡、书目与文献内容的统一检索
- 学习记录、连续学习天数与掌握度统计
- PWA 离线运行与桌面安装
- Capacitor Android / iOS 原生工程
- JSON 数据导入、导出和本地备份

## 下载说明

- `LogosPraxis-v1.0.0-android-debug.apk`：用于体验与测试的 Android 调试安装包。
- `SHA256SUMS.txt`：安装包完整性校验值。
- iOS 版本需在 macOS 上使用 Xcode 从源码构建和签名。

> 调试 APK 并非应用商店生产签名包，请勿将其直接用于正式上架。
