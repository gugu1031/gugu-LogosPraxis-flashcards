# Changelog

All notable changes to LogosPraxis are documented in this file.

## [1.0.0] - 2026-08-28

### Added

- FSRS-4 spaced-repetition review flow with four recall ratings.
- Offline PDF import, rendering, text indexing, highlights and annotations.
- Unified search across cards, books and local PDF pages.
- Structured knowledge browsing and local learning analytics.
- ZIP backup/restore and JSON card import/export.
- Installable PWA plus Capacitor iOS and Android projects.
- Versioned built-in study content with explicit source metadata.

### Security and privacy

- Local-first IndexedDB storage without account or analytics services.
- Android and iOS backup/privacy configuration templates.
- Release signing credentials are read from environment variables only.
