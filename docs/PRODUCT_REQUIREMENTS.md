# LogosPraxis 产品需求与范围

## 1. 产品定位

LogosPraxis 服务于马理论、西方哲学史和西方马克思主义方向的考研学习者。核心目标不是再做一个孤立的闪卡工具或 PDF 阅读器，而是把“考点提取、原文核对、结构归档、重复复习”连接成可循环的学习流程。

核心循环：

1. 在本地文献中阅读并选择原文。
2. 对原文划线、批注或一键生成闪卡。
3. 按学科、人物、年代、题型和流派进入知识库。
4. FSRS-4 根据实际评分安排下一次复习。
5. 从卡片来源一键回到文献页码核对。
6. 统计页观察长期稳定性与学习节奏。

## 2. 一期功能

### 2.1 闪卡

- 正面问题、反面标准答案、答题结构、原著摘录
- 多书目来源与页码
- 学科、理论家、题型、难度、年代、流派标签
- 完全遗忘、困难、尚可、简单四档评分
- FSRS-4 稳定性、难度、提取率和复习间隔更新
- JSON 批量导入导出
- 卡片新建、编辑、删除、筛选
- 253 张版本化内置内容，覆盖核心理论、哲学专题、院校题目与大纲训练题
- 历年题与大纲预测题使用独立来源类型，界面不得混淆

### 2.2 文献图书馆

- 内置 29 本分层书目元数据
- 多 PDF 或 ZIP 批量导入
- 自动按文件名匹配书目
- 未匹配 PDF 自动创建私人书目
- PDF Blob 与逐页文本只存 IndexedDB
- 可移除本地文件并保留书目和闪卡关联

### 2.3 阅读器

- 单页高质量画布渲染
- 可选文字层
- 页码跳转、前后翻页、缩放
- 专注深色背景
- 选择文字后划线、批注、复制、制卡
- 侧栏展示本文献卡片与批注
- 保存上次阅读页码

### 2.4 全局检索

- 内容范围：闪卡、书目、逐页 PDF 正文
- 中文单字与双字索引，英文三字符片段索引
- 按内容类型、书目、学科限定
- PDF 结果跳转准确页码

### 2.5 知识库

- 目标院校专题、其他院校、哲学专题、马克思主义理论独立分区
- 院校题按来源类型、模块、年份、院校和科目筛选
- 哲学与马克思主义理论按人物、年代、模块和题型筛选
- 按历史阶段分组
- 直接维护卡片

### 2.6 统计

- 累计复习、稳定掌握、连续学习、累计时长
- 近 14 日复习折线
- 学科卡片占比
- 最近 12 周打卡热力
- 分书目掌握进度

### 2.7 PWA 与数据

- 离线应用壳缓存
- 手机、平板、桌面布局
- 三套主题
- 申请浏览器持久存储
- 完整 ZIP 备份与恢复

## 3. 远期预留

以下模块只有隔离页面与边界说明，不包含账号、云数据库和远程写入：

- 研友社区
- 在线模考
- 多人协同

如果开发远期模块，必须新建独立的数据访问层，不能让一期页面直接依赖远程服务。

## 4. 非目标

- 不在应用包中内置受保护教材或用户压缩包正文
- 不自动上传用户文献、批注或闪卡
- 不提供 PDF 公开链接或文献分享
- 不在一期实现账号、支付、消息、云同步、内容审核
- 不把第三方网页抓取结果静默保存为本地书籍

## 5. 验收标准

- 无网络时可以打开应用、复习已有卡片、阅读已导入 PDF、检索已有索引
- 刷新页面后数据仍存在
- 选择 PDF 文本可以建立带书目和页码的卡片
- 卡片来源可以返回阅读器对应页
- 完整备份恢复后，PDF 与学习记录可继续使用
- `npm run typecheck`、`npm test`、`npm run build` 均通过
- 360px、768px、1440px 宽度下无横向界面溢出，PDF 放大滚动除外
