# UI 设计规范

## 1. 设计方向

产品是高频、长时、严肃的学习工具。视觉语言取自三类原则：

- Apple 平台：明确层级、低负担转场、直接操作、触控尺寸和安全区
- 不背单词：低饱和背景、专注任务、轻量数据反馈
- 西窗烛：正文留白、宋体阅读、克制书卷感

最终不是对任一产品的像素模仿，而是形成 LogosPraxis 自己的“现代书房”语言。

设计参数：

- 变化度：5/10
- 动效强度：3/10
- 信息密度：6/10

## 2. 颜色

全产品只使用矿物绿作为交互强调色。

纸质主题：

- 背景 `#f1f3ef`
- 表面 `#fafbf8`
- 主文字 `#18201c`
- 强调 `#38624c`

深夜主题：

- 背景 `#171d19`
- 表面 `#202823`
- 主文字 `#e8eee9`
- 强调 `#86ac92`

书卷主题：

- 背景 `#e7dfcf`
- 表面 `#f1eadc`
- 主文字 `#2a2b24`
- 强调 `#49624b`

禁止：

- 紫蓝发光渐变
- 高饱和功能色大面积铺底
- 纯黑与纯白的强烈对撞
- 无语义的彩色状态点

## 3. 字体

- 界面：苹方、微软雅黑 UI、Noto Sans CJK SC 的系统回退
- 阅读与长答案：思源宋体、Noto Serif CJK SC、宋体回退
- 数字：继承无衬线字体并使用等宽数字特性

字号层级：

- 页面标题：29-42px
- 卡片问题：27-45px
- 区块标题：15-18px
- 正文：13-15px
- 辅助信息：9-11px

## 4. 形状

- 主要卡片：18px
- 控件：12px
- 大型记忆卡：26px
- 分段控件内部：9px
- 标签：仅在确实是标签时使用全圆角
- 书封：6px / 12px 非对称圆角，模拟书脊

## 5. 阴影与材质

- 阴影只用于浮层、记忆卡、PDF 页面和真正悬浮的内容
- 普通数据区使用边框与留白
- 侧栏允许轻度背景模糊，并提供减少透明度回退
- 亮色阴影带绿色灰调，不使用纯黑阴影

## 6. 交互

- 按钮按下缩放到 0.98
- 路由过渡只做 3-5px 位移和透明度
- 闪卡翻转 520ms，表示信息状态变化
- 进度更新 180-280ms
- 所有动画响应 `prefers-reduced-motion`
- 可操作目标不小于 36px，主要操作不小于 42px

## 7. 页面布局

桌面：

- 固定侧栏 248px，可收为 76px
- 内容最大宽度 1440px
- 首页采用不对称今日任务区
- 阅读器独占视口，右侧 330px 关联面板

平板：

- 侧栏缩为图标
- 双列内容按信息重要性收为单列
- 阅读器侧栏变为覆盖层

手机：

- 底部五项主导航
- 页面水平边距 16px
- 阅读器工具栏只保留页码与核心按钮
- 文本选择菜单固定为横向操作条
- 避免 `100vh`，统一使用 `100dvh`

## 8. 状态规范

加载：

- 页面级结构骨架
- PDF 使用纸页骨架
- 不使用无语义旋转圆环

空状态：

- 说明为什么为空
- 给出一个明确下一步

错误：

- PDF 导入错误保留在具体书目
- 备份与导入错误使用短提示，不吞掉错误原因
- 可重试操作不清理原有正常数据

## 9. 无障碍

- 所有图标按钮都有中文 `aria-label`
- 键盘可操作复习、翻页、缩放与弹窗关闭
- 正文和控件达到 WCAG AA 对比度
- 不用颜色单独表达状态
- 图表有文本化 `aria-label`
- 选择与焦点环使用同一强调色

## 10. 素材与许可

- 图标使用 Phosphor Icons
- 应用图标为项目专属几何书本与括号图形
- 不使用第三方书封扫描图
- 内置书目用程序化排版封面，避免未授权封面与廉价插画
- 界面字体优先系统已有的免费字体回退，不从 CDN 追踪或下载
