# 分阶段迭代计划

## 一期 A：离线核心

状态：已实现

- Vue 3 + Vite + TypeScript 工程
- Dexie 数据库
- 内置书目
- FSRS-4 闪卡
- PDF 导入、渲染和索引
- 划线、批注、一键制卡
- 全局检索
- 知识库
- 数据统计
- PWA
- 完整备份

## 一期 B：上架前强化

目标：把当前 PWA 变成可提交 TestFlight 的离线 iOS 应用。

- 在 macOS 上生成 Capacitor iOS 工程
- 增加原生文件选择与分享适配器
- 根据实际构建生成 `PrivacyInfo.xcprivacy`
- 增加崩溃恢复与大文件导入分片
- 增加 VoiceOver、动态字体和横屏验收
- 准备 App Store 截图、描述、支持页、隐私政策 URL
- TestFlight 小范围验证
- 对安装包做第三方 SDK 与网络请求审计

## 二期：阅读增强

- Apple Vision 本地 OCR
- 目录与书签
- 坐标级高亮
- 批注颜色与导出
- EPUB 阅读器
- 多窗口阅读
- Apple Pencil 手写批注

## 三期：学习增强

- 真题卡片模板
- 卡组与专题计划
- FSRS 参数个性化拟合
- 错题回流
- 章节级掌握热图
- 复习提醒

## 四期：可选同步

前提：用户明确需要跨设备。

- 端到端加密
- 文献 Blob 与结构化数据分开同步
- 冲突解决与版本历史
- 账户删除
- 导出和数据可携带
- 网络故障下继续本地写入

## 五期：社区与协作

必须先完成内容审核和权限系统。

- 公共卡组只分享自创内容与短引用
- 举报、屏蔽、审核、申诉
- 社区条款与联系渠道
- 协作空间权限
- 远程删除和本地缓存失效
- 付费前评估 App Store 内购规则

## 每阶段共同门槛

- 数据迁移可回滚
- 旧备份可导入
- 无网络时不破坏一期核心
- 隐私标签与政策同步更新
- 第三方依赖许可和安全审计
- 桌面、平板、手机回归测试
