# LogosPraxis 隐私说明

更新时间：2026-07-27

## 当前版本处理的数据

LogosPraxis 在用户设备上处理：

- 用户主动导入的 PDF
- PDF 逐页文本索引
- 闪卡及复习状态
- 阅读划线、批注和页码
- 学习时长和复习统计
- 主题设置

## 数据传输

当前一期没有账号、云同步、分析统计、广告或远程数据库。上述数据不会由应用上传到开发者服务器。

“开放资源”功能只在用户点击后打开外部网站。外部网站有自己的隐私政策，LogosPraxis 不控制其数据处理。

## 数据存储

数据保存在浏览器 IndexedDB 或 iOS/Android 应用的私有沙盒中。Android 版本关闭系统云备份；iOS 版本会把 WebKit 学习数据标记为不进入系统云备份。用户可以：

- 导出完整 ZIP 备份
- 导出闪卡 JSON
- 移除单本或全部本地 PDF
- 通过卸载应用删除应用容器数据

在原生应用中，导出操作会先在应用 Cache 目录生成临时文件，再由用户主动选择系统分享目标。应用不会自动选择接收方或上传到开发者服务器。

## 第三方内容

应用不在安装包中提供受保护教材正文。用户导入内容由用户自行管理，应用不提供公开分享或在线分发功能。

## 未来变化

如果未来增加账号、同步、社区或分析服务，隐私政策、应用内提示和 App Store 隐私标签必须在功能上线前同步更新。

## 联系

正式上架前需在此填写可公开访问的支持邮箱与隐私政策网页地址。
