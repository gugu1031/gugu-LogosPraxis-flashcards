# LogosPraxis 使用说明

## 1. 本地启动

环境：

- Node.js 22 或更高版本
- npm

在项目目录运行：

```powershell
npm install
npm run dev
```

终端会显示本地地址。浏览器打开后，首次运行会自动建立本地数据库。

## 2. 导入 PDF

单本关联：

1. 打开“文献”。
2. 找到内置书目。
3. 点击“关联 PDF”。
4. 选择对应文件。
5. 等待书目卡显示“已导入”。

批量导入：

1. 点击右上角“批量导入”。
2. 可同时选择多个 PDF，也可选择 ZIP。
3. 系统根据文件名匹配内置书目。
4. 未匹配文件会进入“拓展阅读 / 未分类”。
5. ZIP 中只处理 PDF，EPUB 会忽略。

建议先在系统中解压特别大的压缩包，再分批选择 PDF，降低手机内存压力。

## 3. 阅读与批注

1. 在已导入书目点击“继续阅读”。
2. 使用顶部页码、前后按钮或左右方向键翻页。
3. 使用加减按钮或键盘 `+`、`-` 缩放。
4. 选择页面文字后出现操作条。
5. 选择“划线”“批注”“制卡”或“复制”。

制卡时会自动写入：

- 书目 ID
- 当前页码
- 选中原文

## 4. 复习闪卡

1. 首页点击“开始复习”。
2. 先闭卷组织答案。
3. 点击卡片或按空格翻面。
4. 按 1 到 4 评分：
   - 1 完全遗忘
   - 2 困难
   - 3 尚可
   - 4 简单
5. 系统立即计算下一次复习日期。

卡片上的“查看来源”会打开关联文献与页码。

## 5. 使用知识库专题

1. 打开“知识库”。
2. 选择任一目标院校专题，可继续限定“大纲题/历年真题”、知识模块、年份和题型。
3. 选择“其他院校”，可按院校、年份、科目和题型查找。
4. “哲学专题”和“马克思主义理论”已分开，可按模块、人物、年代和题型浏览。
5. 标为“2027 大纲题 · 非真题”的内容是依据考试大纲编写的训练题，不是历年原卷。

在背诵页选择相应的大纲题标签，可集中复习采用递进答案结构的训练卡。

## 6. 批量导入闪卡

设置页支持 JSON 数组。最小格式：

```json
[
  {
    "front": "问题",
    "back": "答案"
  }
]
```

完整卡片可先用“导出卡片”获得当前格式，再复制修改。发生 ID 冲突时会生成新 ID，不覆盖现有卡片。

## 7. 全文检索

1. 打开“检索”，或按 `Ctrl K` 后选择全局检索。
2. 输入概念、人物、流派或原文片段。
3. 可限定闪卡、PDF、书目。
4. 可限定某本书或某个学科。
5. PDF 结果点击后直接打开匹配页。

扫描版 PDF 没有文本层时不会出现原文结果，需要先做 OCR。

## 8. 完整备份

导出：

1. 打开“设置”。
2. 点击“导出完整备份”。
3. 保存 ZIP 到安全位置。

ZIP 包含：

- 本地 PDF
- 逐页文本与检索索引
- 闪卡与 FSRS 状态
- 复习记录
- 批注
- 设置

恢复：

1. 点击“导入备份”。
2. 选择 LogosPraxis ZIP。
3. 确认替换当前本地数据。
4. 等待成功提示。

## 9. 安装 PWA

桌面 Chrome 或 Edge：

1. 打开本地或 HTTPS 部署地址。
2. 点击地址栏安装图标。
3. 确认安装。

iPhone 或 iPad：

1. 使用 Safari 打开 HTTPS 地址。
2. 点击分享。
3. 选择“添加到主屏幕”。

离线能力在首次完整打开后生效。

## 10. 生成 iOS 工程

Windows 可以开发和构建 Web 部分，但最终 iOS 工程、签名和提交需要 macOS 与 Xcode。

在 macOS 克隆项目后：

```bash
npm install
npm run ios:sync
npm run ios:open
```

随后在 Xcode 26 或更高版本设置 Team、Bundle ID、签名证书和版本号。Android 与 iOS 的完整构建命令见 `docs/MOBILE_BUILD.md`，上架清单见 `docs/APP_STORE.md`。

## 11. 常见问题

PDF 导入失败：

- 确认文件不是 EPUB 改后缀
- 尝试在系统 PDF 阅读器打开
- 移除密码
- 特大文件分批导入

全文检索为空：

- 确认书目状态是“已导入”
- 等待逐页索引完成
- 扫描件先做 OCR

数据可能被浏览器清理：

- 设置页点击“申请持久存储”
- 定期导出完整备份
- 不要使用无痕模式

手机空间不足：

- 在设置中移除不常用 PDF
- 保留书目和卡片，之后可重新关联文件
